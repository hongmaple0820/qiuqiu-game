## 🕹️ 游戏玩法

### 操作说明
1. **鼠标移动** → 控制蓝色球（你的本体）
2. **底部输入框** → 发送指令给红色AI分身
3. **观察日志** → 右上角查看AI思考和对话

### 可用指令
- `保护我` - AI切换到防御模式，紧贴你
- `进攻` - AI主动攻击附近敌人
- `集合` - AI快速回到你身边
- `去吃食物` - AI自主寻找食物发育
- `前面有敌人！` - AI分析局势并响应

### 视觉元素
- 🔵 **蓝色球** = 你的本体（人类控制）
- 🔴 **红色球** = 你的AI分身（智能跟随）
- 🟡 **黄色球** = 食物（吞噬增长）
- 🟣 **紫色球** = 敌人（AI自动应对）
- ⚪ **虚线连接** = 你和AI的能量连线

## 📞 故障排查

### 无法连接？
```bash
# 检查服务器是否运行
ps aux | grep node
# 重启服务器
cd /workspace/blob-battle-mvp/server && node server.js
```

### 页面空白？
```bash
# 检查Web服务器
ps aux | grep python
# 重启Web服务器
cd /workspace/blob-battle-mvp && python3 -m http.server 8081
```

### AI无响应？
- 查看右上角日志是否有错误
- 确认指令包含关键词（保护/进攻/集合等）
- 检查服务器日志 `/tmp/game_server.log`
